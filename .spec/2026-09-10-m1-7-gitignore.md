## Contexto

Issue #57: las últimas 4 líneas de `.gitignore` (113-116) tienen comentarios inline:

```
113:.angular/             # Angular CLI cache (residual pivote Ionic)
114:.playwright-mcp/      # Playwright logs (navegador local)
115:www/                  # Build output residual (Ionic Capacitor copy)
116:node_modules/.cache/  # Build caches genéricos
```

`git check-ignore`:
- `.angular/` → exit 1 (NOT ignored)
- `.playwright-mcp/` → exit 1 (NOT ignored)
- `www/` → exit 1 (NOT ignored)
- `node_modules/.cache/` → exit 0 (ignored via línea 46 `node_modules/`, redundante)

`git status --ignored` muestra `??` para los 3 primeros, es decir, untracked.

## Problema

`git add -A` o `git add .` añadiría estos directorios al repo (`.angular/`, `.playwright-mcp/`, `www/`) inadvertidamente. Especialmente peligroso `.playwright-mcp/` (logs locales de navegador, pueden tener info de debugging) y `.angular/` (caché Angular CLI, residual del pivote Ionic, varios MB).

## Objetivo

1. **`.angular/`, `.playwright-mcp/`, `www/`, `node_modules/.cache/` quedan correctamente ignorados** después de la corrección.
2. `git check-ignore -v .angular/` → exit 0.
3. `git status --ignored` muestra `!!` para los 4 paths.
4. Comentario header del bloque sigue explicando el bloque.

## Fuera de alcance

- Renombrar bloques, reorganizar `.gitignore`.
- Eliminar los directorios reales (el usuario puede hacerlo después).
- Modificar `.gitignore` para otros patrones no relacionados.

## Arquitectura afectada

### Modificar

- `.gitignore` líneas 113-116: eliminar comentarios inline (mantener los paths). El header `# Residual de pivote / runtime / tooling cache (NO commitear)` (línea 112) ya documenta el bloque entero.

```gitignore
# Residual de pivote / runtime / tooling cache (NO commitear)
.angular/
.playwright-mcp/
www/
node_modules/.cache/
```

### Crear
- `scripts/check-gitignore.spec.ts` o `__tests__/gitignore.spec.ts` — test que verifica `git check-ignore` retorna exit 0 para los 4 paths.

**Recomendación:** crear `src/__tests__/quality/gitignore.spec.ts` que ejecute `child_process.execSync('git check-ignore ...')` y verifique resultados.

### No tocar
- Otros archivos.
