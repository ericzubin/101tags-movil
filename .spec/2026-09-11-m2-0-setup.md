## Contexto

F2 (catálogo) cubre 5 issues (#12-#16). Sin infraestructura común, esas 5 issues pelearían por archivos compartidos (`src/core/services/`, `src/components/`, `src/core/models/`). M2.0-setup introduce la base UNA sola vez para que las 5 issues corran sin conflictos.

- `GET /api/home-content` (hero/featured_category/featured_media/ribbon)
- `GET /api/catalog/categories?segment=X`

## Objetivo

1. **Tipos**: `common.model.ts`, `home-content.model.ts`, `catalog.model.ts` con shapes exactos del backend.
2. **Query keys factory**: `src/core/query/keys.ts` con factories estables para invalidación correcta.

4. **Utils**: `media-url.ts` (resolver URLs), `format-currency.ts` (MXN), `snake-camel.ts` (mapper genérico).
5. **snake→camel centralizado en httpClient** (después de `safeJsonParse`). TODOS los responses se normalizan antes de llegar al caller.
6. **Componentes UI base**: `Button`, `Skeleton`, `EmptyState`, `ErrorState`, `Image` (wrapper expo-image).
7. **expo-image** agregado como dep directa + mock en jest.
8. **Tests**: ~45 tests nuevos (tipos, services, utils, componentes).

### `src/core/services/catalog-service.ts`

```ts
import { httpClient } from '@/core/api/client';
import type {
  CatalogFilters,
  CategoriesResponse,
  FilterOptions,
  Paginated,
  ProductDetail,
  ProductSummary,
  SponsoredAdsResponse,
} from '@/core/models/catalog';

export const catalogService = {
  async getCategories(segment: string = 'basicos'): Promise<CategoriesResponse> {
    return httpClient.request<CategoriesResponse>('/catalog/categories', {
      method: 'GET',
      query: { segment },
    });
  },

  async getProducts(filters: CatalogFilters = {}): Promise<Paginated<ProductSummary>> {
    return httpClient.request<Paginated<ProductSummary>>('/catalog/products', {
      method: 'GET',
      query: serializeFilters(filters),
    });
  },

  async getProductBySlug(slug: string): Promise<ProductDetail> {
    return httpClient.request<ProductDetail>(`/catalog/products/${encodeURIComponent(slug)}`, {
      method: 'GET',
    });
  },

  async getFilters(segment: string = 'basicos', category?: string): Promise<FilterOptions> {
    return httpClient.request<FilterOptions>('/catalog/filters', {
      method: 'GET',
      query: { segment, category },
    });
  },

  async getSponsoredAds(): Promise<SponsoredAdsResponse> {
    return httpClient.request<SponsoredAdsResponse>('/catalog/sponsored-ads', {
      method: 'GET',
      query: { recordImpressions: false },  // preview mode
    });
  },
};

// Helpers para serializar arrays como CSV (backend acepta CSV o JSON)
function serializeFilters(filters: CatalogFilters): Record<string, string | number | boolean | undefined> {
  const out: Record<string, string | number | boolean | undefined> = {};
  if (filters.q) out.q = filters.q;
  if (filters.category?.length) out.category = filters.category.join(',');
  if (filters.subcategory?.length) out.subcategory = filters.subcategory.join(',');
  if (filters.sizes?.length) out.sizes = filters.sizes.join(',');
  if (filters.colors?.length) out.colors = filters.colors.join(',');
  if (filters.priceMin !== undefined) out.price_min = filters.priceMin;
  if (filters.priceMax !== undefined) out.price_max = filters.priceMax;
  if (filters.segment) out.segment = filters.segment;
  if (filters.supplierId !== undefined) out.supplier_id = filters.supplierId;
  if (filters.featured !== undefined) out.featured = filters.featured ? '1' : '0';
  if (filters.inStock !== undefined) out.in_stock = filters.inStock ? '1' : '0';
  if (filters.onSale !== undefined) out.on_sale = filters.onSale ? '1' : '0';
  if (filters.sort) out.sort = filters.sort;
  if (filters.page !== undefined) out.page = filters.page;
  if (filters.perPage !== undefined) out.per_page = filters.perPage;
  return out;
}
```

⚠️ **`recordImpressions`**: el backend espera snake_case en query params. Pero httpClient.query acepta `Record<string, string|number|boolean|undefined>`. El mapper snake→camel **NO se aplica a query params** (solo a response body). Los query params deben ir en snake_case explícito o el backend no los entiende. Mantener `record_impressions: false` snake_case explícito en query.

### `src/core/utils/media-url.ts`

```ts
import { getApiBaseUrl } from '@/constants/env';

/**
 * Resolves a media path from the backend to a fully-qualified URL.
 * Backend returns paths like `/storage/products/x.jpg` or `/tienda/x.jpg`.
 * If the path is already absolute (http:// or https://), returns it as-is.
 */
export function resolveMediaUrl(path: string | null | undefined): string | null {
  if (!path) return null;
  if (/^https?:\/\//.test(path)) return path;
  if (path.startsWith('//')) return `https:${path}`;
  const base = getApiBaseUrl().replace(/\/$/, '');
  const normalized = path.startsWith('/') ? path : `/${path}`;
  return `${base}${normalized}`;
}
```

const MXN = new Intl.NumberFormat('es-MX', {
  style: 'currency',
  currency: 'MXN',
  minimumFractionDigits: 2,
  maximumFractionDigits: 2,
});

export function formatMXN(amount: number | string | null | undefined): string {
  if (amount === null || amount === undefined) return '$0.00';
  const n = typeof amount === 'string' ? parseFloat(amount) : amount;
  if (Number.isNaN(n)) return '$0.00';
  return MXN.format(n);
}

### `src/core/utils/snake-camel.ts`

```ts
/**
 * Recursively converts snake_case keys to camelCase in plain objects.
 * Arrays are traversed; primitives and null/undefined are preserved.
 * Date objects and class instances are preserved as-is.
 */
export function toCamel<T = unknown>(input: unknown): T {
  if (input === null || input === undefined) return input as T;
  if (Array.isArray(input)) {
    return input.map((item) => toCamel(item)) as unknown as T;
  }
  if (typeof input !== 'object') return input as T;
  if (input instanceof Date) return input as T;
  if (Object.prototype.toString.call(input) !== '[object Object]') {
    // RegExp, Map, Set, etc. — preserve as-is
    return input as T;
  }
  const out: Record<string, unknown> = {};
  for (const [key, value] of Object.entries(input as Record<string, unknown>)) {
    const camelKey = key.replace(/_([a-z0-9])/g, (_, c) => c.toUpperCase());
    out[camelKey] = toCamel(value);
  }
  return out as T;
}
```

export interface SkeletonProps {
  width?: number | string;
  height?: number | string;
  rounded?: boolean;
  testID?: string;
}

export function Skeleton({ width = '100%', height = 16, rounded = false, testID }: SkeletonProps) {
  const opacity = useRef(new Animated.Value(0.4)).current;
  useEffect(() => {
    const loop = Animated.loop(
      Animated.sequence([
        Animated.timing(opacity, { toValue: 1, duration: 800, useNativeDriver: true }),
        Animated.timing(opacity, { toValue: 0.4, duration: 800, useNativeDriver: true }),
      ]),
    );
    loop.start();
    return () => loop.stop();
  }, [opacity]);

  return (
    <Animated.View
      testID={testID ?? 'skeleton'}
      style={{
        width,
        height,
        opacity,
        backgroundColor: '#E5E7EB',
        borderRadius: rounded ? 999 : 4,
      }}
    />
  );
}

## Acceptance Criteria (BDD)

### Tipos

- AC1: `Paginated<T>` tiene `data`, `meta`, `links` con campos exactos.
- AC2: `HomeContentItem` tiene campos snake→camel: `sortOrder`, `startsAt`, `endsAt`, `imageUrl` no (es `image`).
- AC3: `ProductVariantSummary` tiene `priceOverride`, `inStock`, `price`.
- AC4: `FilterOptions` tiene `sizes`, `colors`, `priceMin`, `priceMax`, `categories`, `subcategories`.

### snake→camel mapper

- AC5: `{ user_id: 1, user_name: 'X' }` → `{ userId: 1, userName: 'X' }`.
- AC6: nested objects y arrays se procesan recursivamente.
- AC7: `null`, primitives, Date, RegExp se preservan sin cambios.
- AC8: aplicado en httpClient → response shape normalizado.

## Riesgos / caveats

1. **snake→camel centralizado afecta TODOS los responses**: cualquier caller que asumía snake_case fallará. Auth endpoints ya devuelven camelCase del backend, pero el mapper pasa por ellos también (no-op si ya están en camelCase). **Sin riesgo funcional**; **con riesgo de cambio de tipos si algún caller tiene type assertions explícitas**.
2. **Query params NO pasan por snake→camel**: solo el body. `record_impressions` debe ir snake_case explícito.
3. **expo-image mock**: el mock en jest.setup.js debe cubrir todos los miembros que se importan (`Image`, `ImageBackground`). Si se importa otro (e.g., `Image.Source`), añadirlo.
4. **Componentes UI sin tests E2E**: solo smoke tests. La integración real se valida en M2.1+.
5. **Sin cambios en layout**: el splash sigue funcionando porque no tocamos `_layout.tsx`.
