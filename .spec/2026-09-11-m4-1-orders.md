## Objetivo

Lista paginada de pedidos del cliente (auth) + detalle con items, totales, estado, timeline y tracking cuando exista.

## Contratos (auth:sanctum)

`GET /orders` → **paginator Laravel**: `{ current_page, data:[OrderSummary], per_page, total, ... }`.
`GET /orders/{orderNumber}` → `OrderDetail` (404 si ajeno/inexistente).

`OrderSummary`: `id`, `orderNumber`, `status`, `paymentStatus`, `paymentMethod`, `segment`, `total`, `itemsCount`, `createdAt`, `tracking{carrier,number,timeline}`, `supplierRating{canRate,hasRated,rating{stars,comment,createdAt}|null}`.
`OrderDetail` = resumen + `subtotal`, `shippingCost`, `discountAmount`, `couponCode`, `paymentDueAt`, `paymentInstructions`, `shippingAddress`, `items[{productName,size,color,quantity,unitPrice,totalPrice}]`.

- `tracking.timeline`: estructura JSON del backend (`Order::trackingSteps()`); render tolerante a null/vacío.
- Nota: `GET /orders` vincula pedidos guest previos al usuario (`linkGuestOrdersToUser`).

## Arquitectura

- `src/core/models/order.model.ts`: `OrderSummary`, `OrderDetail`, `OrderItem`, `Tracking`, `SupplierRatingState` (+ toCamel).
- `src/core/services/order-service.ts`: `getOrders(page?)`, `getOrder(orderNumber)`.
- `src/stores/order-store.ts` (o hooks TanStack Query): lista + paginación + detalle; `status`/`error`; `refresh`.
- UI: `src/app/(tabs)/account.tsx` → acceso "Mis pedidos"; `src/app/orders/index.tsx` (lista paginada + pull-to-refresh) y `src/app/orders/[orderNumber].tsx` (detalle). Registrar rutas en `_layout`.
- Reusar `Paginated<T>` existente (camelCase plano) y patrones de `catalog`/`api`.

## Estados

- Lista vacía → EmptyState; error → ErrorState retry; 404/ajeno → estado "no encontrado"; tracking solo si `carrier||number||timeline` presentes.

## Seguridad

- Solo auth; nunca mostrar pedidos de otro usuario; no loggear PII/direcciones.

## Escenarios BDD

- **AC1**: `getOrders()` llama `GET /orders` y mapea el paginator (`data`, `currentPage`, `total`).
- **AC2**: lista muestra `orderNumber`, total, estado y fecha; paginación carga página siguiente.
- **AC3**: detalle muestra items (nombre, talla/color, cantidad, unitario, total), subtotal, envío, descuento, total.
- **AC4**: timeline se renderiza en detalle; tracking (carrier/número) solo cuando existe.
- **AC5**: pedido ajeno/inexistente → 404 → estado no encontrado (no crash).
- **AC6**: vacío/error → EmptyState/ErrorState con retry.
