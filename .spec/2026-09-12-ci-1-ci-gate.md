# Spec: CI-1 — CI obligatorio para PRs a `developer`/`main` (#58)

**Status**: APPROVED · **Spec ID**: 2026-09-12-ci-1
**Issue**: #58 ([101M][DEVOPS][F0]) · **Branch**: `chore/ci` (base `developer`) · **Depends**: F0

---

## Objetivo

Gate de CI liviano y reproducible **solo para PRs hacia `main`** (promoción/release), **sin builds móviles caros**. Un fallo de typecheck/lint/formato/tests hace fallar el check. Los PRs a `developer` **no** corren este gate (flujo de integración rápido, sin CI).

## Decisión de formato (importante)

El baseline de `developer` **no** pasa `pnpm format:check` (94 archivos, deuda pre-existente). Un `format:check` global dejaría todo PR en rojo. Decisión: el job de formato valida **solo los archivos cambiados respecto a la base del PR** (evita merges de código nuevo sin formatear) y se documenta que una pasada global de formato queda como deuda técnica separada (fuera del alcance de #58). No se reformatean 94 archivos en este PR (evita refactor no relacionado y conflictos con el stack de features).

## Workflow (`.github/workflows/ci.yml`)

- Trigger: `pull_request` → `branches: [main]`; `push` a `main`; `workflow_dispatch`.
- `permissions: contents: read` (mínimos); sin secrets; no imprimir `.env`/tokens.
- `concurrency: group: ci-${{ github.workflow }}-${{ github.ref }}`, `cancel-in-progress: true`.
- Node **24** (`actions/setup-node@v4`).
- pnpm **desde `packageManager`** (`pnpm/action-setup@v4` con `run_install: false`), `actions/setup-node` cache `pnpm`.
- `pnpm install --frozen-lockfile` (falla si `package.json`/lock desincronizados).
- Jobs:
  1. `quality` (rápido): `pnpm typecheck` + `pnpm lint` + `pnpm format:changed`.
  2. `tests`: `pnpm test:ci` (necesita `quality`).
- `format:changed`: script `scripts/format-changed.mjs` que calcula archivos cambiados vs base (`${{ github.base_ref }}`/`HEAD~`) y corre `prettier --check` sobre ellos (los ya ignorados por `.prettierignore` se omiten).
- **No** se ejecuta EAS, `prebuild --clean` ni export en cada PR. Workflow nativo manual/release separado (`workflow_dispatch`) documentado, no obligatorio por commit.

## Criterios de aceptación (de #58)

- [x] Workflow versionado bajo `.github/workflows/` para PRs a `main`.
- [x] Node 24 + pnpm declarado por el proyecto (sin versión flotante).
- [x] Lockfile congelado (falla si desincronizado).

- [x] Estrategia nativa pesada separada (manual/release).
- [ ] Branch protection/ruleset en **`main`** (requiere configuración del repo por el usuario) → **BLOQUEADO (settings del repo)**.

## Fuera de alcance

- Reformat masivo del repo (deuda técnica documentada).
- Branch protection (config de GitHub, la hace el usuario).
- EAS Build en CI.

## Verificación

- YAML válido; script `format:changed` probado localmente sobre archivos cambiados (verde/de rojo según el caso).
- `pnpm typecheck`/`pnpm lint` exit 0.
